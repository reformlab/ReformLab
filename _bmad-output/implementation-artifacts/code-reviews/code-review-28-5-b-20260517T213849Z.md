## 🐛 Correctness & Safety

### 1. 🎭 Lying Test — AC-1: Chaining Invariant Never Asserted

**📍 `tests/orchestrator/test_multi_period_decisions.py:368-381`**

The test name and docstring claim: _"Assert `incumbent_heating_t == heating_chosen_{t-1}` for all households."_ The actual assertions are:

```python
assert all(inc is not None for inc in current_incumbents)
assert all(inc is not None for inc in prev_incumbents)
```

That's it. `current_incumbents` is `pop.tables["menage"].column("incumbent_heating")` — the **post-state of year N**, not the previous year's choices. The test never fetches `heating_chosen_{t-1}` (or `to_alternative_ids` from the transition record) and never compares it to `current_incumbents`. A bug where `apply_choices_to_population` overwrites incumbents with garbage values would still pass this test as long as the values aren't `None`.

The `TransitionRecord.to_alternative_ids` available in `state.data[TRANSITION_LOG_KEY]` is never cross-referenced against the following year's incumbents. The invariant is not pinned.

### 4. 🎭 Lying Test — AC-2: Reproducibility Is Tautological

**📍 `tests/orchestrator/test_multi_period_decisions.py:463-473`**

`_run_multi_year_scenario` builds `result.metadata` as:

```python
metadata={
    "start_year": config.start_year,
    "end_year": config.end_year,
    "seed": config.seed,
    "step_pipeline": ["discrete_choice", "state_update"],
}
```

This is a literal dict constructed from `config` fields. It is **always byte-identical between two runs** because it contains no computed output — just the config echo. The test compares this dict, not a `RunManifest` with `data_hashes`, `output_hashes`, `seeds`, `assumptions`, integrity hash, etc. A non-deterministic bug in the actual logit draws or writeback would be completely invisible to this test.

The AC says "two manifests are byte-for-byte identical" — the actual `RunManifest.to_json()` is never called.
