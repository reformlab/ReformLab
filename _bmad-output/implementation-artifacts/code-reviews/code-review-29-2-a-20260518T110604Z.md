### Documentation Error: "Removed" vs "Replaced" for `irpp` (MEDIUM)

`result_normalizer.py:46` reads:

```python
# Removed: irpp -> income_tax
#   Rationale: "irpp" is a generic name that does not exist in OpenFisca-France.
```

This is factually wrong. `irpp` was **replaced**, not removed. The `income_tax` English output still exists — it now comes from `irpp_economique`. This also contradicts the story's own migration plan table, which correctly records the action as "Replace" for `irpp`.

```python
_MINIMUM_REQUIRED_COLUMNS: frozenset[str] = frozenset({
    "income", "disposable_income", "carbon_tax",
```

Before Story 29.2, `taxe_carbone → carbon_tax` was in `_DEFAULT_OUTPUT_MAPPING`, so `carbon_tax` could be produced by any live run.
