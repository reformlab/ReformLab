## 🐛 Correctness & Safety

### 🔴 [CRITICAL] Bug: AC-4 VIOLATED - Badge variant bypass pattern still exists

The entire premise of Story 27.14 was to fix Badge component styling bypasses, but the implementation only fixed 3 specific instances while missing at least 3 others that use the EXACT same anti-pattern with different variants.

**📍 Locations:**
- `frontend/src/components/population/PopulationUploadZone.tsx:126` - Uses `variant="secondary"` with `bg-green-50 text-green-700` override
- `frontend/src/components/population/PopulationUploadZone.tsx:161` - Uses `variant="secondary"` with `bg-red-50 text-red-700` override  
- `frontend/src/components/engine/CalibrationPanel.tsx:25` - Uses `variant="outline"` with `bg-amber-50 border-amber-300 text-amber-700` override

**🔄 Reproduction:** Run `grep -r 'variant=.*className=.*bg-' frontend/src/components` - found 3 instances of badge variant bypass pattern that were NOT fixed.

**⚠️ Impact:** This is the same anti-pattern the story claimed to eliminate. The bypasses use semantic variants (`secondary`, `outline`) but then override colors anyway, defeating the purpose of the Badge design system.

**💡 Fix:** 
- Line 126: Use `variant="success"` instead of `variant="secondary"` with green overrides
- Line 161: Use `variant="destructive"` instead of `variant="secondary"` with red overrides
- Line 25: Use `variant="warning"` instead of `variant="outline"` with amber overrides

### 🔴 [CRITICAL] Bug: Task 3.1 FAILED - Audit was fundamentally incomplete

The audit command in Task 3.1 uses grep pattern `variant="default".*bg-` which only finds badges using `variant="default"` with color overrides. This completely misses bypasses using OTHER variants (like `secondary`, `outline`) with color overrides.

**📍 Task 3.1 grep command:** `grep -r 'variant="default".*bg-' frontend/src/components`

**🔄 Why it fails:** The pattern would NOT find:
- `variant="secondary" className="...bg-green-50"` 
- `variant="outline" className="...bg-amber-50"`

**⚠️ Impact:** The audit gave a false sense of completion. Task 3.2 claims "only the 3 known bypasses should remain" but this was never actually verified because the grep pattern was too narrow.

**💡 Fix:** Use a broader grep pattern: `grep -r 'variant=.*className=.*bg-' frontend/src/components` or run multiple patterns for each variant.
