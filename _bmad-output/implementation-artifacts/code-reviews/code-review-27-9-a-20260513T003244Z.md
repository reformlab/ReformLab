- 📍 `frontend/src/utils/naming.ts:353-371`
- 🔄 Reproduction: Call `formatParameterForName(44.5, "€/tonne")` → returns `"44.5eur"`. This string contains a period (`.`) which is not in `[a-z0-9-]`. Any `generatePortfolioSuggestion()` call with a decimal parameter value will silently produce an invalid portfolio name that fails `validatePortfolioName()`. ### Bug 2 — `slugifyTypeAndCategory` has no length cap; single-policy path skips `truncateSlug`

- 📍 `frontend/src/utils/naming.ts:213-216` and `naming.ts:447-449`
- 🔄 Reproduction: Create a category with label `"A".repeat(60)`. `slugify()` caps at 64 chars. `slugifyTypeAndCategory("transfer", slugify("A".repeat(60)))` = `"transfer-" + 60_chars` = 69 chars. This inconsistency means long category labels silently violate the 64-char contract in AC-7 for single-policy compositions.
