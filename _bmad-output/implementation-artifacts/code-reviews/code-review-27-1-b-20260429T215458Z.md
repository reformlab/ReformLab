## 🐍 Pythonic Crimes & Readability

- **Constant dict rebuilt per call:** `_POLICY_TYPE_TO_PARAMS` is declared inside `_build_policy_config()` as a local `dict` literal on every invocation.
  - 📍 `src/reformlab/server/routes/portfolios.py:219–224`
  - The dict maps `PolicyType` → `type[PolicyParameters]` and never changes. It should be a module-level constant (or at worst a `functools.cache`).

- **Dead env-var writes in new tests:** Three new tests (`test_create_single_policy_succeeds`, `test_create_returns_version_id`, etc.) do `os.environ["REFORMLAB_REGISTRY_PATH"] = str(tmp_path)` then `del os.environ[...]` in a `finally` block. Because `_isolate_portfolio_registry` already patches `dependencies._registry` directly via `monkeypatch.setattr`, the env var has zero effect on `get_registry()` (which returns the already-set singleton). The reads and deletes are noise that could confuse future maintainers and silently mask fixture isolation bugs.
  - 📍 `tests/server/test_portfolios.py:238–248, 252–267, 310–323`
  - Note: these were copy-pasted from pre-existing tests that were written before the fixture was updated. They compile and pass — but mean nothing.
