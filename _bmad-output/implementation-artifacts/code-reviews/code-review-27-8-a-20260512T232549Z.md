### 🔒 [HIGH] Accessibility: Disabled Button Missing Native Attribute

- 📍 `WorkflowNavRail.tsx:288-306`
- ⚠️ Impact: Keyboard users can still tab to and activate the disabled Inspect button

The `SubStepIndicator` component uses `aria-disabled` but lacks the native `disabled` attribute:
```typescript
<button
  type="button"
  aria-disabled={disabled ? "true" : undefined}  // ✅ Present
  // ❌ Missing: disabled={disabled}
  onClick={disabled ? undefined : onClick}
```

**Why this matters:** 
- `aria-disabled` is informational for screen readers but doesn't prevent keyboard interaction
- Native `disabled` attribute removes button from tab order and prevents Enter/Space activation
- Current implementation relies on `onClick={disabled ? undefined : onClick}` which is not the correct accessibility pattern
