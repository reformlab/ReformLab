## 🏛️ Architectural Sins

- **[9/10] Broken Radix Context Usage:** `renderDomainSection` uses `CollapsibleTrigger` and `CollapsibleContent` inside a plain `<div>`, never wrapped in `<Collapsible>`. Radix UI's Collapsible relies on React context established by `<CollapsiblePrimitive.Root>`. Without it, `CollapsibleContent` has no context to read `open` state from — the `open` prop it receives isn't a recognized prop on `CollapsiblePrimitive.Content` (it belongs on `Root`). Behavior is undefined: content may always render or never render.
  - 📍 `TechnologyStep.tsx:334-465` (missing `<Collapsible open={isExpanded}>` wrapper around the domain section)
  - 💡 Fix: Wrap `renderDomainSection` body in `<Collapsible open={isExpanded} onOpenChange={() => handleToggleExpanded(domain)}>` and remove the manual `onClick` on `CollapsibleTrigger`.
