### Fragile Subsidy Ineligibility Assertions

- **🐛 Bug:** The integration test asserts `subsidy_values[2] == 0.0` (household with `salaire_de_base = 25000`) but the formula uses `menage("revenu_disponible", period)`, not `salaire_de_base`. In OpenFisca-France's computation chain, `revenu_disponible` for `salaire_de_base = 25000` is likely well below 25000 after social charges (~22%), employee taxes, and the complex `revenu_disponible` formula. Whether it falls below 20000 depends on unverified OpenFisca-France formula outputs. If `revenu_disponible < 20000`, then `subsidy_values[2] == 150.0`, breaking the assertion.
  - 📍 `tests/computation/test_openfisca_extension.py:315-331`
  - 🔄 Reproduction: Install OpenFisca-France and run `python -c "from openfisca_france import CountryTaxBenefitSystem; from openfisca_core.simulation_builder import SimulationBuilder; ..."` to compute `revenu_disponible` for a single person with `salaire_de_base = 25000`. If the result is < 20000, this test would fail with the next OpenFisca-France formula update.
