### 6. Manifest Reproducibility — Canonical JSON Must Strip More Fields

**Benefit:** Prevents false negatives where reproducible runs compare as non-identical due to legitimate non-deterministic fields.
**Source:** `governance/manifest.py` `RunManifest` fields

**Current Gap:**
The example `_canonical_json` helper strips only `timestamp` and `run_id`, but `RunManifest` has at minimum: `manifest_id` (UUID generated fresh each time), `created_at` (timestamp), `integrity_hash` (hash over the whole manifest including `manifest_id`). All three are non-deterministic per run.

**Suggested Addition:**
```python
def _canonical_json(self, manifest: RunManifest) -> str:
    """Strip all non-deterministic fields before byte comparison."""
    import json
    from dataclasses import asdict

    NON_DETERMINISTIC = {"manifest_id", "created_at", "integrity_hash", "run_id"}
    data = asdict(manifest)
    for k in NON_DETERMINISTIC:
        data.pop(k, None)
    return json.dumps(data, sort_keys=True, default=str)
```
