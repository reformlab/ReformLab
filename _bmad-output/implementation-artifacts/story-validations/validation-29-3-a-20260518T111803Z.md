
### 3. Assertion Precision for Floating-Point Values

**Value:** Prevents flaky tests due to floating-point comparison issues

**Suggestion:**
Custom variables return floats (150.0, 1600.0, etc.). Direct equality checks can be flaky due to floating-point precision. Use pytest.approx() in test examples:

```python
# Instead of:
assert normalized.column("subsidy_amount")[0].as_py() == 150

# Use:
assert normalized.column("subsidy_amount")[0].as_py() == pytest.approx(150.0, abs=0.01)
```

Add this as a note in the test example or in a "Testing Best Practices" section.
