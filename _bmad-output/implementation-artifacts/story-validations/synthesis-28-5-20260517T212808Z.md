### Step Pipeline Construction for Multi-Period Tests

Multi-period discrete choice tests require manually assembling the step pipeline. The correct ordering is:

```python
from reformlab.orchestrator.types import OrchestratorConfig
from reformlab.discrete_choice.step import DiscreteChoiceStep
from reformlab.discrete_choice.logit import LogitChoiceStep
from reformlab.discrete_choice.heating import HeatingStateUpdateStep
from reformlab.orchestrator.carry_forward import CarryForwardStep
from reformlab.computation.mock_adapter import MockAdapter

# Build step pipeline for multi-year heating decisions
step_pipeline = [
    DiscreteChoiceStep(domain=heating_domain),  # Compute cost matrix
    LogitChoiceStep(domain=heating_domain),     # Make choices
    HeatingStateUpdateStep(domain_key="heating"),  # Write incumbents, track transitions
    CarryForwardStep(),  # Thread population_data to next year
]

config = OrchestratorConfig(
    start_year=2025,
    end_year=2029,
    seed=42,
    initial_state={"population_data": population_1k},
    step_pipeline=step_pipeline,
    adapter=MockAdapter(),  # Use mock adapter to avoid real OpenFisca calls
)
```
