**Impact:** Developer implements the wrong fix (redundant deps) or wastes time researching whether the bug still exists. If they add "fix" code where no bug exists, they risk accidentally weakening the `manuallyEditedScenarioNames` guard.

}, [

The effect DOES rerun when `portfolioName` or `populationIds` change. The guard DOES re-evaluate on every rerun. The "current behavior" description is wrong.
